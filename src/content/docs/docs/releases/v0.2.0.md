Caeser is a Go CI investigation engine. It connects failed-run evidence to the
source revision that produced it, traces failure locations and values through
the code, ranks evidence-backed leads, and records what remains unresolved.
Developers can continue from the report with Caeser, their own tools, or their
preferred coding assistant.

## Included

- Evidence-first GitHub Actions diagnosis with a report, artifact, and pull
  request comment.
- Go source analysis, typed call relationships, bounded SSA assertion tracing,
  causal traces, and ranked investigation leads.
- Separate, opt-in paths for reproduction, base/head comparison, focused Go
  probes, model-assisted analysis, and repair proposals with verification.
- Investigation records that preserve evidence, hypotheses, activities,
  experiments, patches, and verification outcomes.

The default CI workflow does not automatically run every deeper investigation
path. Leads and model interpretations are not guaranteed root causes or fixes.

## Evaluation

Existing localization cases are development-exposed and do not provide an
independent accuracy estimate. The latest ten-case rerun produced three
exact-function hits and one abstention. It confirms reproducibility of that
evaluation, not accuracy on unfamiliar failures. No accuracy or time-savings
guarantee is made.
